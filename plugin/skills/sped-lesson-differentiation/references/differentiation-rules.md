# 특수교육 차별화 pedagogy — 성취수준(A/B/C) × 자극-반응 pool 축

## 지원 축 = 국가 자료의 "성취기준별 성취수준 기술을 위한 풀(pool)"

국립특수교육원 자료(예: 기본 교육과정 평가자료 hwp)는 성취기준마다 **자극 방식**(학생이
정보를 어떻게 받아들이는지)과 **반응 방식**(학생이 무엇으로 표현·수행하는지)을 조각
문구로 제공하고, 이 조각을 조합해 개별 학생의 성취수준 문장을 짓도록 설계돼 있다.
예([4과학01-01] 자석):

- 자극 조각: "자석과 여러 가지 물체를 가까이했을 때 나타나는 현상을" → "바라보고" /
  "소리를 들어보고" / "느껴보고" / "체험해 보고"
- 반응 조각: "자석에 붙는 물체와 붙지 않는 물체를" → "표로 정리한다" / "스티커로
  표시한다" / "말한다" / "몸짓으로 가리킨다"

**이 스킬은 범용 1~5 척도를 쓰지 않는다.** 대신 매 성취기준마다 그 기준 고유의 pool에서
조합을 골라 그룹을 짓는다 — 국가가 이미 검증해둔 문구라 더 구체적이고 성취기준마다
다른 조합이 나온다(모든 수업이 "전신체 촉진"으로 시작하지 않는다).

pool 안의 조각들은 대체로 **구체적·전신체적인 것 → 추상적·독립적인 것** 순으로
느슨하게 배열돼 있다(예: "몸짓으로 가리킨다" < "말한다" < "표로 정리한다"). 이 순서를
R3·R7의 진입점·용암 배치에 쓴다. 정확한 순서는 성취기준마다 다르므로 매번 pool
원문을 보고 판단한다 — 고정된 서열표를 만들지 않는다.

**성취수준(A/B/C)은 별개 축이다.** 국가 자료의 "성취기준별 교육과정 성취수준"
(지식·이해/과정·기능/가치·태도 3범주, 학년군 단계별 내용요소)이 여기 해당한다. 두 축은
독립이다 — 어떤 A/B/C 학생이든 어떤 자극-반응 조합이든 필요로 할 수 있다.

---

## R1 — 산출 구조

**교사용 통합 차별화 수업안 1종 + 순수 학생용 학습지 3종(1모둠/2모둠/3모둠). 그룹별
별도 수업안 3종을 만들지 않는다.**

모든 학생이 함께하는 단계(도입, 전체 활동, 정리)는 한 번만 쓴다. 그룹별로 갈라지는
단계(개별 과제)는 세 그룹을 한 표에 나란히 보인다.

## R2 — 3범주 범위 보존

**모든 그룹이 원래 성취기준을 다룬다. 지식·이해, 과정·기능, 가치·태도 셋 다 모든
그룹에 나타나야 한다 — 어떤 자극-반응 조합을 쓰든 예외 없다.**

자극-반응 조합이 더 단순(전신체·몸짓)하다고 범주 하나를 통째로 빼거나 활동 자체를
구경으로 바꾸는 것은 차별화가 아니다. **참여도를 보존한다** — 모든 그룹이 같은
현상/활동에 참여한다. 자극을 받는 방식과 반응을 표현하는 방식이 다를 뿐이다.

## R3 — pool에서 진입점 고르기

**해당 성취기준의 pool을 읽고, 그 안에서 상대적으로 구체적인 조합 → 중간 조합 →
추상적/독립적인 조합, 3개를 고른다. 목표(성취기준) 자체를 낮추지 않는다.**

절차:
1. `references/data/`에 해당 성취기준의 pool이 있으면 그대로 읽는다.
2. 없으면(대부분의 성취기준이 아직 미수록) **국가 pool의 패턴을 본떠** 그 성취기준에
   맞는 자극 조각(바라보기/듣기/만지기/체험하기 등 감각 양식)과 반응 조각(가리키기/
   따라하기/말하기/쓰기/설명하기 등 표현 양식)을 새로 만든다 — 국가 자료가 쓰는 어조와
   구체성 수준을 유지한다.
3. 3그룹에 각각 하나씩 배정한다. 1모둠은 상대적으로 구체적인 자극(직접 만지기·체험)
   + 단순한 반응(가리키기·몸짓), 3모둠은 추상적 자극(관찰만으로) + 정교한 반응(문장
   서술·설명)으로 향한다. 정확한 배치는 성취기준마다 다르다 — 이 문서의 표는 예시일
   뿐, 매번 실제 pool을 보고 정한다.

**공통교육과정 관련 성취기준 연계**가 pool 자료에 함께 적혀 있으면(예: "[4과09-01]
관련지어 고려할 수 있음"), 공통교육과정 경로로 각색할 때 그 연계를 인용한다.

## R4 — 허용되는 조합 방식

**목표는 의존을 만드는 게 아니라 그 학생이 실제로 반응할 수 있는 통로로 성취기준에
닿게 하는 것이다.**

피해야 할 실패:
- ❌ pool에 없는 임의의 "쉬운 버전" 활동을 만들어 끼워 넣기 — 반드시 그 성취기준
  자체의 자극/반응 조각에서 고른다
- ❌ 모든 그룹에 같은 자극·같은 반응을 주고 문서만 3벌 만들기(차별화가 아님)
- ❌ 성취기준 적용 시 고려사항(장애 유형별 지침)이 pool 자료에 있는데 무시하기 —
  있으면 반드시 반영한다(예: 시각중복장애 학생을 위한 점자 스티커 등 구체 지침)

허용되는 조합:
- ✓ 자극 조각 + 반응 조각을 그대로 조합해 학생 대면 지시문 생성
- ✓ 같은 자극에 여러 반응 조각을 병렬 제시해 학생이 선택하게 하기(AAC 등 의사소통
  수단이 있는 학생)
- ✓ "성취기준 적용 시 고려사항"에 있는 감각·매체 대체 지침(점자, 확대, 촉각 자료 등)
  그대로 사용

## R5 — 필수 교수학습 장치

| 요소 | 무엇인가 | 어디에 |
|---|---|---|
| **형성 확인** | 체크리스트로 어떤 자극-반응 조합에 실제로 반응했는지 기록 | 그 단계 안 |
| **앵커 활동** | 먼저 끝낸 학생용, 같은 성취기준의 더 정교한 반응 조각으로 확장 | 수업안 끝 + 학습지 3종 |
| **유연한 편성 문구** | 그룹 배정이 이 수업의 관찰에 근거하며 조합을 바꿔 재시도할 수 있다는 진술 | 수업안 머리 콜아웃 |
| **그룹별 예상 반응 + 대응** | 조합별로 흔한 반응/막힘 + 교사의 대응(다른 조합 시도) | 각 그룹 블록 콜아웃 |
| **성취기준 적용 시 고려사항** | pool 자료에 있는 장애 유형별 지침을 그대로 인용 | 해당 그룹 블록 |

각 학습지는 그룹 공통의 성찰/마무리 확인 하나로 끝난다(`shared.reflect_prompt`).

## R6 — 보이지 않는 조정 (불변 원칙)

**그룹 간 같은 성취기준, 같은 활동/자료/맥락. 자극-반응 조합만 다르다.**

통합 수업안에서 공유 활동은 "모든 학생" 아래 한 번만 나온다. 그룹 블록은 **다른
것만** 보인다. 조합이 빠지는 것을 학생에게 알리지 않는다 — 라벨도, 곁말도 없다.

## R7 — 그룹 내 점진적 배치

**각 그룹의 학습지는 구체적인 자극-반응 조합 → 추상적인 조합 순으로 과제를 배열한다.**

예시(반드시 실제 pool로 대체):

| 과제 | 1모둠 | 2모둠 | 3모둠 |
|---|---|---|---|
| 도입 | 만지기/체험하기 → 몸짓으로 가리키기 | 보기/듣기 → 스티커로 표시 | 관찰 → 표로 정리 |
| 본 과제 | 교사 인도 + 단순 반응 | 부분 인도 + 짧은 말 | 독립 관찰 + 설명 |
| 마무리 | 반응 확인(예/아니오) | 짧은 표현 | 문장 서술 |

**확장 품질 검사(3모둠):** 같은 성취기준의 pool 안에서 가장 정교한 반응 조각(설명,
비교, 이유 서술 등)을 요구하는지 확인한다. 단순 반복이나 분량만 늘린 것은 거절한다.

## 문항 형식(포맷) — 그룹마다 다르게 쓴다

**R3–R7이 정하는 것은 자극-반응의 *내용*(어떤 문구를 쓰는가)이고, 이 절이 정하는
것은 그 문구를 학생이 어떻게 답하게 만드는가(문항 *형식*)다. 같은 pool 조각이라도
1모둠과 3모둠은 답란 자체가 달라야 한다** — 둘 다 빈 줄(서술형)만 주는 것은 R2·R4
위반이다(1모둠에게 사실상 못 풀 형식을 준 것과 같다).

국립특수교육원 실제 학습지가 쓰는 세 가지 저지원 형식을 그룹 배치에 맞게 쓴다
(모두 `differentiation.json`의 기존 블록 타입 — 새로 만드는 게 아니라 골라 쓰는 것):

| 형식 | 블록 | 언제 쓰나 | 학생이 하는 일 |
|---|---|---|---|
| **따라쓰기** | `trace` — `{"type":"trace","label":"...","text":"..."}` | 1모둠(가장 구체적) 핵심 개념·정리 문장 | 옅게 미리 인쇄된 정답을 덧쓰거나 그대로 옮겨 쓴다 |
| **보기(단어은행) + 동그라미/선택** | `cards` — `{"type":"cards","items":["단어1","단어2",...]}` (앞에 `**보기**` 문단) | 1~2모둠 분류·명명 과제 | 상자로 늘어선 짧은 단어 중 답을 고르거나 동그라미 한다 — 새로 쓰지 않는다 |
| **서술형 빈 답란** | `workspace`(문장 길이) 또는 `fill_table` | 3모둠(가장 독립적), 또는 명시적으로 A수준·서술 가능 학생이 있을 때 | 스스로 문장·표를 구성해 쓴다 |

**적용 원칙:**
- 1모둠 학습지는 **`trace`와 `cards`(보기) 위주**로 구성한다. 서술형 빈 줄만 여러 개
  이어지는 1모둠 학습지는 R3(진입점 선택) 위반으로 본다 — 국가 pool이 "반응을
  보인다"·"가리킨다"처럼 저지원 반응을 지정했는데 답란이 자유서술형이면 pool과
  형식이 어긋난다.
- 2모둠은 `cards`(보기)로 후보를 주되 표시·기입은 학생이 직접 하게 해 1모둠보다
  지원을 한 단계 줄인다(같은 보기, `workspace` 병행).
- **3모둠(또는 학급에 성취수준이 높은 학생이 있을 때)은 서술형 학습지를 최소 1종
  유지한다** — 모든 그룹을 저지원 형식으로 바꾸는 것도 R2(3범주 범위 보존)·R7(확장
  품질) 위반이다. 3모둠은 지금처럼 `workspace`(줄글)와 설명·비교·이유 서술을 그대로
  쓴다.
- `trace`에 넣는 문장은 **국가 pool 조각을 그대로 조합한 것**이어야 한다(R4) — 임의로
  쉬운 문장을 새로 짓지 않는다.

### 분량 — 저지원 형식이라고 문항을 줄이지 않는다

**형식을 쉽게 바꾸는 것과 분량을 줄이는 것은 다르다.** 실제 국가 학습지(진로와
직업·실과 등)는 1모둠용이라도 도입 설명 + 다단계 과제로 상당한 분량을 갖춘다 —
쉬운 형식일수록 오히려 **단계를 잘게 쪼개 문항 수를 늘려서** 인지 부담을 나눈다.
"1모둠이니까 간단하게"는 문항 1~2개로 끝내도 된다는 뜻이 아니다 — 매 문서 아래
기준을 최소선으로 채운다:

1. **도입 설명 블록 1개.** 각 문서(교사용 포함)는 첫 활동 앞에 오늘 배울 것을
   학생 언어로 짧게 풀어주는 `callout`(kind: `student-task`)이나 `labeled`
   블록을 둔다 — 성취기준 원문을 그대로 던지지 않고 "오늘은 자석이 무엇에
   붙는지 알아볼 거예요"처럼 쉬운 말로 먼저 맥락을 준다.
2. **활동당 최소 3단계.** 자극-반응 조합 하나를 통짜 과제 하나로 두지 않고,
   "① 물건 살펴보기 → ② 대보고 결과 확인하기 → ③ 표시/기입하기"처럼 하위
   단계로 쪼갠다. 각 하위 단계는 그 자체로 하나의 `cards`/`trace`/`fill_in`
   문항이다 — 국가 학습지가 "버거 종류 고르기 → 메뉴 구성 고르기 → 사이드메뉴
   고르기"처럼 단계를 늘어놓는 것과 같은 패턴이다.
3. **학습지 전체 최소 4~5개 문항.** 도입 1 + 본 활동(3단계 이상) + 형성 확인
   1로 세면 자연히 채워진다. 그룹 간 문항 *개수*는 비슷하게 맞추고, 달라지는
   것은 형식(R3–R7)과 각 문항의 인지 부담이다 — 1모둠 학습지가 3모둠보다
   눈에 띄게 얇으면 실패로 본다.
4. **사진·삽화는 넣지 않는다(저작권 가드레일 유지).** 실제 학습지의 사진 자리는
   `cards`의 짧은 단어 상자로 대체한다 — 위 ②의 "단계 쪼개기"로 분량을
   보충하지, 존재하지 않는 이미지 자리로 대체하지 않는다.

## R8 — 그룹 군집화와 기본값

**학급 학생들을 대표 3그룹으로 군집화한다(옵션 A — 학생 수와 무관하게 문서 3종).**

절차:
1. 학생별로 어떤 자극 방식(시각/청각/촉각/체험)과 반응 방식(몸짓/말/글/조작)이
   맞는지, 그리고 성취수준(A/B/C, 국가 자료가 있으면)을 정리한다.
2. 이 성취기준의 pool을 놓고, 학생들의 자극-반응 프로필과 가장 가까운 조합 3개를
   고른다 — 1모둠(가장 구체적) / 2모둠(중간) / 3모둠(가장 독립적).
3. 한 그룹 안에 학생이 여럿이고 세부가 다르면, 그룹의 기본 조합은 같이 쓰되 개별
   학생 메모(콜아웃)로 차이를 반영한다(예: 같은 2모둠이라도 한 학생은 "말한다", 다른
   학생은 "AAC로 표현한다").
4. 학생 수가 적어 조합이 이미 3개 이하면 군집화 없이 그대로 쓴다.

**정보가 없을 때 기본값:** 해당 성취기준 pool의 처음/중간/마지막 조합을 각각 1/2/3
모둠에 배정하고, 첫 출력 턴에 밝힌다: *"구체적인 학생 프로필이 없어 pool의 대표
조합 세 가지를 순서대로 배정했어요. 학생별 선호 자극·반응 방식을 알려주시면
다시 맞출게요."*

**pool 자료가 없는 성취기준일 때** R3의 절차 2(자체 제작)를 따르고, 첫 출력 턴에
밝힌다: *"이 성취기준은 국가 pool 자료가 아직 없어 일반적인 특수교육 모범 사례로
자극-반응 조합을 만들었어요."*

원본 ko12 스킬(및 그 원본 anthropics/k12-teacher-skills)의 문서 템플릿·JSON 스키마·
밀도 규칙·교차 점검(O6)·학생 대면 언어 규칙·강점 관점 표현 규칙을 그대로 따른다 —

- "그룹 편성" 절: 각 그룹이 어떤 자극-반응 조합을 쓰는지 + 포함된 성취수준(A/B/C)을
  함께 적는다.
- "성취기준 적용 시 고려사항"이 pool 자료에 있으면 콜아웃으로 별도 인용한다
  (`shared.accommodation_note` 같은 키로 — 특정 그룹에만 해당하면 그 그룹 문서에만).
- 학습지 그룹명은 "1모둠/2모둠/3모둠"처럼 중립적인 이름.
